# 今晚誰會贏？— 烤肉聚會積分遊戲

手機優先的實體聚會積分系統。約 15 人烤肉現場使用：任務、九宮格拍照、懸賞、團康、自動計分、最終排名與獎金結算。

## 原則

- 遊戲融入聚會，不是讓大家一直低頭滑手機
- 任務自由完成、玩家自行勾選
- 結算前玩家只看得到自己的分數，看不到排名

## Stack

- Next.js 15 + React 19 + TypeScript + Tailwind
- V1：Node 記憶體 store + API 輪詢（單實例即可玩）
- 可選：Supabase（`supabase/schema.sql`）

## 開發

```bash
npm install
npm run dev
```

- 首頁：http://localhost:3000
- 管理員預設 PIN：`2468`（可用 `ADMIN_PIN` 覆蓋）

## 玩家流程

掃 QR → 加入遊戲 → 選名字 → 設定/輸入 4 位 PIN → 底部導覽：

首頁 / 任務 / 遊戲 / 我的

## 管理員

右下角「管理員」→ PIN

- 開始活動（發放九宮格／秘密任務／懸賞／目標循環）
- 團康：不要跟我一樣、誰寫的
- 最後按鈕大戰、留一句話
- 鎖定積分 → 最終結算 → 60 秒贈與第二名
